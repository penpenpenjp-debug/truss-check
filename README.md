# トラスショック（英国2022年9月）は日本で起きるか：国債と通貨の値動き・保有者・制度を英国と比べる

レポート：`index.html`（GitHub Pages で公開）

英国2022年9月の国債（ギルト）とポンドの急落と、2024〜2026年の日本を、同じ物差しで比べた検証です。2026年11月19日に作ったもので、その時点で公表されていたデータの結果です。個人の検証で、Bank of England・日本銀行・財務省などの見解ではありません。投資の助言でもありません。

## 結論の要約

- 英国型の「数日で自己増殖する急落」の予兆は、日本のデータにありません。30年金利の3営業日の上昇は、英国トラス期が +112.8bp（前2年の日々の振れの11.6倍）で、ポンドも4.7%下落しました。日本の財政が原因の局面（2026年1月）は +31.1bp（5.8倍）で、円はほぼ動いていません。
- ただし、値動きの指標は英国でも危機を事前に示しませんでした。「起きにくい」と言える根拠は構造の違い（レバレッジを使う年金 LDI が確認できない、日銀が売却せず急騰時の買い入れを明記している、海外の保有比率が低い）です。
- 小さな「金利上昇＋円安」の日は2026年に増えています。起きるとすれば、長期金利がじわじわ上がり円安が続く形の可能性が高いと考えます。

## 数字の検算

```
python verify.py
```

必要なもの：Python 3.10 以上、pandas、numpy。外部への通信はしません。`data/` の CSV だけから、レポートの表（30年金利の急騰の大きさと倍率、「金利上昇＋通貨安」の日数、出来事ごとの累積の動き、日本国債の保有比率、経常収支）を再現します。

## データ（`data/`）

| ファイル | 中身 | 出典 |
|---|---|---|
| uk_gilt_nominal_zero_coupon_daily.csv | 英国債の名目ゼロクーポン利回り（10年・30年、%、日次、2019年〜） | Bank of England, Yield curves（nominal spot curve） |
| gbpusd_daily_frb_h10.csv | 1ポンドあたりのドル（ニューヨーク正午、日次、2019年〜。米国の休日は欠ける） | Board of Governors of the Federal Reserve System, H.10 Foreign Exchange Rates |
| jgb_yield_daily_mof.csv | 日本国債の利回り（2年・10年・30年・40年、%、日次、1999年〜） | 財務省「国債金利情報」 |
| usdjpy_daily_boj.csv | ドル円（東京市場 17時、日次、1999年〜） | 日本銀行「時系列統計データ」（FM08） |
| jgb_holders_quarterly_boj_flow_of_funds.csv | 日本国債の保有者別残高（時価、億円、四半期末、2000年〜）。国庫短期証券を除く・含むの2通り | 日本銀行「資金循環統計」 |
| japan_current_account_monthly_boj.csv | 日本の経常収支（季節調整前、億円、月次） | 日本銀行・財務省「国際収支統計」 |

計算の決まり：

- 英国の30年は BoE が推計したゼロクーポン（スポット）利回りで、日本は財務省の利付債の利回りです。作り方が違います。英国の3営業日の上昇は、10年 +88bp、20年 +99bp、30年 +113bp で、年限による差は倍率の差を説明するほどではありません。
- 英国の金利はロンドンの引け、ポンドはニューヨーク正午で、時刻がずれます。日本は東京の引けとドル円の東京17時です。
- 倍率は「k 営業日の上昇 ÷（出来事の k 営業日前より前の2年の日次変化の標準偏差 × √k）」です。
- 保有比率の「合計」は資金循環統計の国債の発行残高側の合計（全部門の保有の計）で、部門の内訳（「うち〜」）を足すと二重に数えます。

## 載せていないもの

- 5年 CDS の値：データ提供元の利用条件で再配布できないため、公開版のレポートとデータから外しました。
- 英国債の海外保有比率（約31〜34%）：英国債務管理庁（DMO）の四半期報告の値を引いた資料によります。データとしては入れていません。
- 制度や出来事の記述（BoE の介入、LDI、日本銀行の国債買い入れ減額、財務省の発行計画、海外勢の売買シェアなど）は、レポート本文に挙げた公表資料と報道によります。
